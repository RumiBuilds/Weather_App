# Weather App 

A modern Android Weather App that provides users with current weather information based on their location or selected city.

## Features

- Displays current temperature and weather conditions
- Search weather by city
- Location-based weather information
- Shows additional weather details such as humidity and wind speed
- Clean and user-friendly interface
- Real-time weather data using an API

## Technologies Used

- Kotlin
- Android Studio
- XML
- Android SDK
- REST API
- JSON
- Git & GitHub
