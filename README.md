# Weather App 

A modern Android Weather App that provides users with current weather information based on their location or selected city.

## Features

- Displays current temperature and weather conditions
- Search weather by city
- Location-based weather information
- Shows additional weather details such as humidity and wind speed
- Clean and user-friendly interface
- Real-time weather data using an API

## Technologies Used

- Kotlin
- Android Studio
- XML
- Android SDK
- REST API
- JSON
- Git & GitHub

## Setup & Installation

- Clone this repository:
   ```bash
   git clone https://github.com/RumiBuilds/Weather_App.git

- Open the project in Android Studio.
- Wait for Gradle to finish syncing.
- Add your Weather API key if required.
- Build and run the application on an Android device or emulator.

## API Key

For security, API keys should not be uploaded directly to GitHub.

Store your API key securely and make sure it is not committed to the repository.
